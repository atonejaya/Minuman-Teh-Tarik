# @One Consignment - Backend API

Proyek backend untuk sistem penjualan konsinyasi @One.

## Persyaratan
- Node.js v18+
- PostgreSQL v14+

## Memulai

1. Clone repositori ini.
2. Jalankan `npm install`.
3. Duplikat `.env.example` menjadi `.env` dan isi kredensial yang sesuai.
4. Jalankan `npx prisma migrate dev` (Setelah Prisma disiapkan).
5. Jalankan `npm run dev`.
